Проверь, достаточно ли базы знаний `ai-docs` для темы: `$ARGUMENTS`.

Выдай:

- какие документы покрывают тему (с `id`);
- какие вопросы остаются без ответа в базе;
- для каждого пробела — предлагаемый документ: каталог, `id`, `title`, `type`
  и 3–5 тезисов содержания.

Ничего не создавай и не изменяй — только отчёт.
