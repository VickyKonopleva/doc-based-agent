# Указатели на документы вашей базы знаний

Заполняется командой один раз после подключения базы. Агент читает этот файл,
чтобы не тратить шаги на поиск документов, которые нужны ему в каждой задаче.

Формат строки: `тема — путь относительно корня базы или id из frontmatter`.
Неизвестно или такого документа нет — оставьте прочерк: агент найдёт сам через
`docs_read()` и `docs_search`, просто за большее число шагов.

```yaml
# Процесс
spec_driven_flow:   -     # как работать с PR аналитики (черновик: docs/proposed-ai-docs/spec-driven-flow.md)
ticket_lifecycle:   -     # жизненный цикл задачи
branching_commits:  -     # имена веток, формат коммитов
pull_request:       -     # шаблон описания PR
definition_of_done: -     # DoD
review_checklist:   -     # чеклист код-ревью

# Правила кода
code_style:         -     # стиль Java
framework:          -     # конвенции Spring Boot
rest_api:           -     # контракты REST
persistence:        -     # БД, JPA, миграции
error_handling:     -     # формат ошибок
observability:      -     # логи, метрики, трейсинг
security:           -     # секреты, авторизация, валидация
testing:            -     # требования к тестам

# Навигация
service_cards_dir:  -     # каталог с карточками сервисов, например 40-projects/
glossary:           -     # глоссарий
build_runbook:      -     # команды локальной сборки
```

Правило для агента: указатель — это подсказка, а не ограничение. Если по
указанному пути документа нет или он не о том, искать обычным способом и
сказать человеку, что указатель устарел.
