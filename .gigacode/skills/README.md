# skills/ — намеренно пусто

У агента нет предустановленных скилов. Это не упущение, а конструктивное
решение: процедура работы живёт в `ai-docs/`, который сопровождает команда
и который можно менять без изменения конфигурации агента.

Скил добавляется сюда только если он описывает **работу самого агента**
(например, разбор многомодульного проекта), а не доменные правила разработки.
Всё, что отвечает на вопрос «как у нас принято писать код», идёт в `ai-docs/`.

Если агенту по ходу задачи понадобилась недостающая **операция** — он создаёт
себе инструмент через `tool_create`, см.
`ai-docs/50-runbooks/agent-self-extension.md`.
