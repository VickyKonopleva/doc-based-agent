# Документы, предложенные для вашей базы знаний

Здесь лежат готовые документы, **которых агенту не хватает**, если ваша база
знаний складывалась до перехода на вход «тикет + PR аналитики».

Это не часть агента и не часть вашей базы. Это черновики: скопируйте нужное
в свой репозиторий `ai-docs`, приведите к своему формату frontmatter и
добавьте в `INDEX.md`. После этого удалите отсюда, чтобы не держать две копии.

| Файл | Зачем |
|---|---|
| `spec-driven-flow.md` | как читать PR аналитики, трассируемость требований, стоп-ситуации |
| `merge-request-additions.md` | добавки в ваш шаблон описания MR: ссылка на спеку и таблица требований |

Проверить, чего ещё не хватает именно вашей базе, можно командой агента:

```
/docs-gap идемпотентность консьюмеров
```

или прогнав реальную задачу в режиме плана — агент перечислит, что ему
пришлось додумать:

```bash
./scripts/run-agent.sh BACK-1234 456 --plan
```
