# Добавки в шаблон описания MR

Черновик. Влейте эти разделы в свой существующий документ про оформление MR —
агент заполняет их автоматически, но только если они описаны в базе знаний.

## Разделы, которые нужно добавить

```markdown
## Источники
- Тикет: BACK-1234
- Спецификация: analytics!456 — ссылка на PR в репозитории аналитики

## Требования
| ID | Требование | Где реализовано | Чем покрыто | Статус |
|----|-----------|-----------------|-------------|--------|
| R1 | ретраи 1s/2s/4s + джиттер | `PaymentCallbackService` | `…Test#shouldRetryWithBackoff` | сделано |
| R4 | метрика попыток | `CallbackMetrics` | `…IT#shouldCountRetries` | сделано |
| R5 | таймаут 5s | — | — | **не сделано: вынесено в BACK-1300** |

Все требования с приоритетом `must` закрыты, либо перечислены здесь с
объяснением, почему нет.

## Расхождения со спецификацией
Что сделано иначе, чем написано в спеке, и почему. Нет расхождений — «нет».

## Решения вне ai-docs
Что пришлось додумать, потому что правила нет в базе знаний, и каким
документом это стоит закрыть. Нет таких — «нет».
```

## Добавки в чеклист MR

```markdown
- [ ] все требования `must` из спецификации закрыты и покрыты тестами
- [ ] ссылка на PR аналитики проставлена
- [ ] расхождения со спецификацией описаны
```

## Правило

MR без ссылки на PR аналитики не принимается к ревью: без неё невозможно
проверить, то ли реализовано, что заказывали.
