# Глоссарий

> Заполняется доменными терминами вашего контура. Агент читает его, чтобы
> правильно понять формулировку тикета и назвать сущности в коде так же,
> как их называет бизнес.

## Процесс

| Термин | Значение |
|---|---|
| DoD | Definition of Done, `proc-dod` |
| ADR | Architecture Decision Record, `20-architecture/adr/` |
| MR | merge request |
| DLT | dead letter topic, топик необработанных сообщений |

## Домен (пример: платежи)

| Термин | Код | Значение |
|---|---|---|
| Платёж | `Payment` | намерение списать средства по заказу |
| Попытка | `PaymentAttempt` | одно обращение к платёжному шлюзу |
| Возврат | `Refund` | частичный или полный возврат проведённого платежа |
| Холдирование | `Authorization` | блокировка суммы без списания |
| Клиринг | `Capture` | списание ранее захолдированной суммы |
| Идемпотентность | — | повторный вызов с тем же ключом даёт тот же результат |
| Outbox | `outbox_event` | таблица событий для надёжной публикации в Kafka |

## Технические сокращения

| Сокращение | Расшифровка |
|---|---|
| ПДн | персональные данные |
| MCP | Model Context Protocol, протокол подключения инструментов |
| IT | integration test (суффикс класса) |
