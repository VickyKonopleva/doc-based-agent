# Чеклист код-ревью

Агент прогоняет этот чеклист по собственному диффу **до** создания MR и
исправляет найденное.

## Корректность

- Граничные случаи и ошибки обработаны, а не проглочены.
- Нет гонок при конкурентном доступе; нет изменяемого разделяемого состояния.
- Транзакционные границы совпадают с бизнес-операцией.
- Внешние вызовы имеют таймаут и понятное поведение при отказе.

## Данные

- Нет N+1 запросов (проверить `fetch`-стратегии и циклы с обращением к репозиторию).
- Индексы под новые запросы.
- Миграция не блокирует таблицу надолго.

## Контракт

- Имена полей и коды ошибок по `conv-rest-api` и `conv-error-handling`.
- Удаление/переименование поля ответа — breaking change.

## Безопасность

- Валидация входных данных на границе.
- Нет конкатенации SQL/JPQL из пользовательского ввода.
- В логи не попадают токены, ПДн, номера карт.
- Проверка прав выполняется на сервере, а не на клиенте.

## Читаемость

- Имена отражают домен, а не реализацию.
- Метод помещается на экран; вложенность не глубже трёх уровней.
- Нет дублирования, которое уже решено существующей утилитой.
