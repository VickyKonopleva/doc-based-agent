# Безопасность

## Секреты

- В репозитории секретов нет. Никогда. Ни в тестах, ни в `application-local.yml`.
- Источник — переменные окружения, подставляемые из Vault/CI.
- Коммит с секретом = инцидент: ротация ключа, затем удаление из истории.
- `.env`, `*.p12`, `*.jks`, `id_rsa` — в `.gitignore`.

## Аутентификация и авторизация

- Проверка прав — на сервере, на каждом эндпоинте, по умолчанию «запрещено».
- `@PreAuthorize` на методах прикладного сервиса, не только в конфиге Security.
- Проверка владения ресурсом обязательна: наличие роли не даёт доступ к чужому
  объекту.
- JWT проверяется по подписи и `exp`; `alg: none` отвергается.

```java
@PreAuthorize("hasRole('PAYMENT_OPERATOR')")
public Payment refund(PaymentId id, Principal principal) {
    Payment payment = paymentRepository.findById(id).orElseThrow(() -> new PaymentNotFoundException(id));
    payment.assertOwnedBy(principal.getName());   // не только роль, но и владение
    ...
}
```

## Валидация ввода

- Jakarta Validation на всех входящих DTO (`@Valid` в контроллере).
- Белый список допустимых значений, а не чёрный список запрещённых.
- Ограничение размера коллекций и строк на входе.
- Загружаемые файлы: ограничение размера и типа, имя не используется как путь.

## Инъекции

- Только параметризованные запросы. Склейка SQL/JPQL из ввода запрещена.
- Имя колонки для сортировки — через белый список, не подстановкой строки.
- Внешние команды через `ProcessBuilder` с массивом аргументов, не через shell.

## Данные

- Пароли — только Argon2id/bcrypt, никогда не обратимым шифрованием.
- ПДн не попадают в логи, трейсы и сообщения об ошибках.
- Шифрование чувствительных полей на уровне приложения, если так требует ADR.

## Зависимости

- Новая зависимость — только с обоснованием в MR.
- Сборка падает при HIGH/CRITICAL уязвимости (OWASP Dependency-Check).

## Нельзя

- Отключать проверку сертификатов, в том числе «временно для теста».
- `permitAll()` на эндпоинте, меняющем состояние.
- Хранить токены в логах, БД в открытом виде или в query-параметрах.
- Собственная криптография.
