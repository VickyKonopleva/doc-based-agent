# fixtures/ — данные для оффлайн-прогона

Нужны только для `npm run smoke`: сервер проверяется целиком, без доступа к
Jira, Bitbucket и к вашей базе знаний.

| Каталог | Что это | Какой переменной включается |
|---|---|---|
| `ai-docs/` | крошечная база знаний | `AI_DOCS_PATH` |
| `jira/` | тикет `BACK-1234` | `JIRA_PROVIDER=mock` |
| `spec/` | PR аналитики `456` с файлами спецификации и нерешённым тредом | `SPEC_PROVIDER=mock` |
| `services/` | список репозиториев сервисов | `SERVICES_PROVIDER=mock` |

Это **не** ваши данные и не образец для базы знаний. Менять содержимое можно
только вместе с проверками в `scripts/smoke-test.mjs`.

Клонирование сервисов фикстурой не подменяется: smoke-тест создаёт настоящий
bare-репозиторий во временном каталоге и клонирует его по-настоящему.
